# Cybersmith Scripts
These are scripts used by Cybersmith to perform our cybersecurity testing work.

## ConfigForNessusScan.ps1
An interactive script that configures a Windows device for scanning by Nessus based on user inputs.

## ConfigForNessusScanDisableAll.ps1
A non-interactive script that reverts a Windows device back to the default settings removing the standard changes required to make a Nessus scan work.

## ConfigForNessusScanEnableAll.ps1
A non-interactive script that enables the settings on a Windows device back to make a Nessus scan work.
